# Tugas Eksplorasi Open Source & Ringkasan Repository

## 1. Konsep Open Source & Repository
* **Open Source:** Model pengembangan perangkat lunak di mana kode sumber (*source code*) dibagikan secara terbuka kepada publik agar siapa saja dapat melihat, menggunakan, memodifikasi, dan mengembangkannya bersama.
* **Repository (Repo):** Tempat penyimpanan digital (seperti folder pusat di GitHub) yang memuat seluruh file dan riwayat kode dari suatu proyek.

## 2. Studi Kasus: Repository React (`facebook/react`)
* **Apa itu React?** 
  Sebuah *library* JavaScript *open-source* buatan Meta (Facebook) yang digunakan untuk membangun antarmuka pengguna (*User Interface* / UI) pada aplikasi web.
* **Teknologi & Keunggulan:**
  * **Virtual DOM:** Membuat performa aplikasi menjadi sangat cepat karena hanya memperbarui bagian halaman yang berubah saja.
  * **Component-Based:** Memungkinkan kode dibagi menjadi komponen-komponen kecil yang bisa digunakan kembali (*reusable*).
* **Bagaimana Kolaborasi Terjadi:**
  * Kontributor dari seluruh dunia membuat salinan (*fork*) dari repository ini.
  * Setelah melakukan perbaikan atau fitur baru, mereka mengirimkan *Pull Request* (PR) kepada pengelola (*maintainer*) untuk ditinjau dan digabungkan ke proyek utama.
